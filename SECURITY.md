# Security policy

Security fixes go to the default branch (`master`). There is no separate LTS line.

## Reporting a vulnerability

Please **do not** open a public issue for an undisclosed security problem.

1. Use **[GitHub Security Advisories](https://github.com/gHashTag/t27os/security/advisories)** for this repository (preferred), or
2. contact the maintainers through a private channel published on the org profile.

Include a description and the impact, steps to reproduce, and the affected spec or board image.
