# Измерения времени: baseline vs synth-spec

## СТАТУС: ДАННЫХ НЕТ — ФАЙЛ ЯВЛЯЕТСЯ ЗАГОТОВКОЙ

Предыдущая версия этого файла содержала числа (27-29s, разбиение по этапам),
которые НЕ были получены реальными прогонами: ни yosys, ни nextpnr-xilinx,
ни fasm2frames не запускались в этой сессии. Числа отозваны как
неверифицированные. По закону проекта (скорость/точность только с измерением
и командой) и прямому приказу владельца ("не обещать ускорение, пока нет
сопоставимых прогонов") этот файл не является доказательством чего-либо.

## Что нужно, чтобы файл стал настоящим

1. `tri fpga synth-spec` должен собраться и запускаться (сейчас подкоманды
   нет в бинарнике, cli/tri/src/fpga.rs идентичен git HEAD).
2. OpenXC7-инструменты по SSOT §8 (yosys, nextpnr-xilinx, prjxray
   fasm2frames/xc7frames2bit, chipdb) — проверить наличие: T27_OPENXC7.
3. Baseline: >=5 прогонов ручного рецепта на одной спеке
   (спека ещё не выбрана окончательно; кандидат specs/ternary/gft_relu.t27),
   фиксируя время каждого этапа командой `/usr/bin/time` или Instant в tri.
4. synth-spec: те же >=5 прогонов, тот же part/top/xdc/seed.
5. Медиана/min/max, число успешных прогонов, чистое и прогретое состояние.

## Замерены и верифицированы на этой машине (единственное пока)

- cargo build --release -p tri: ~45s (HEAD-состояние, без synth-spec).
- t27c gen-verilog и t27b verilog на gft_relu.t27: оба завершаются
  успешно, 31ms и 25ms соответственно (разовый прогон diff-дорожки,
  не в счёт таблицы до/после).
