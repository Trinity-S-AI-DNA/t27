# VIZ-DISTILL-GRAPH -- the spec corpus as one interactive picture

**Bucket:** `docs/nona-03-manifest/` (cross-cutting tooling).
**Spec (SSOT):** [`specs/viz/distill_graph.t27`](../../specs/viz/distill_graph.t27).
**Issue:** #12218.

## What it is

A force-directed picture of every `use` edge in the repository, shaped after
Distill's *A Gentle Introduction to Graph Neural Networks*
(distill.pub/2021/gnn-intro) -- the **method** is borrowed, the bytes are not:

- hover a node and its neighbourhood lights (the specs it stands on, and the
  specs standing on it) while everything else dims;
- the same edges appear a second time as an adjacency matrix of the busiest
  specs, and hovering either view lights the other;
- colour carries one attribute -- the directory a spec lives in -- and the
  legend names every colour it paints.

Nothing is fetched: the page names no origin, and
`page_names_origin() == false` settles that on every
`t27c test-report` run instead of anyone trusting it.

## Why the page is a `.t27` spec

A hand-written `.html` is forbidden (owner rule 2026-10-05, AGENTS.md "Only
t27"; the own-language gate says the same in its own words). So the page **is**
the spec: `PAGE` is an array of lines, `t27c gen-js` emits it unchanged, and
the tests above pin the lines that carry the contract (the doctype, the two
view containers, the closing tag). Edit the spec; the artefact is derived.

## Materialise it locally

The artefact lands in `build/` (gitignored, never committed) because it is
derived output. Run this from the repository root:

```bash
python3 - <<'PY'
import json, subprocess, sys
from pathlib import Path
root = Path.cwd()
spec = (root / "specs/viz/distill_graph.t27").read_text(encoding="utf-8")
lines, inside = [], False
for raw in spec.splitlines():
    if raw.startswith("pub const PAGE"):
        inside = True
        continue
    if inside and raw.startswith("];"):
        break
    if inside and raw.startswith('    "'):
        body = raw.strip().rstrip(",")
        lines.append(body[1:-1].replace('\\"', '"'))
if not lines:
    sys.exit("no PAGE lines read from the spec")
edges, nodes = [], set()
out = subprocess.run([str(root / "target/release/t27c"), "use-edges"],
                     cwd=root, capture_output=True, text=True, check=True).stdout
for row in out.splitlines():
    p = row.split("\t")
    if len(p) == 2:
        nodes.update(p)
        edges.append({"s": p[0], "t": p[1]})
data = json.dumps({"nodes": [{"id": n} for n in sorted(nodes)], "edges": edges},
                  separators=(",", ":"))
page, injected = [], False
for ln in lines:
    if ln.startswith("const DATA = "):
        page.append("const DATA = " + data + ";")
        injected = True
    else:
        page.append(ln)
if not injected:
    sys.exit("the DATA line was not found -- the spec changed shape")
dest = root / "build/viz/spec-graph.html"
dest.parent.mkdir(parents=True, exist_ok=True)
dest.write_text("\n".join(page) + "\n", encoding="utf-8")
print(f"{dest}: {len(nodes)} nodes, {len(edges)} edges")
PY
open build/viz/spec-graph.html
```

Expected first line of output: `.../build/viz/spec-graph.html: 1114 nodes,
9483 edges` (the counts track the corpus, so they move as specs do).

## What the gates say about it

```bash
t27c spec-status specs/viz/distill_graph.t27   # IMPLEMENTED
t27c test-report specs/viz/distill_graph.t27   # 5 tests, 5 pass, 0 FAIL
t27c coverage specs/viz/distill_graph.t27      # Tested: 2 (100%)
t27c seal specs/viz/distill_graph.t27 --verify # its seal holds
```

`t27c lint` reports `fn '<name>' has no test or invariant` for both functions:
that lint wants a `test` block **nested inside** the function body, while every
spec in this repository keeps tests at module level (`specs/tri/loop/lesson.t27`
reports the same warning 59 times). The rule the CI enforces is coverage, and
coverage is 100%.

## Deliberately not committed

- `build/viz/spec-graph.html` -- derived, and a new `.html` is refused by the
  gate whatever its provenance.
- the materialiser script above -- a new `.py` would be a new foreign file.
  It lives here, in a `.md`, which the gate allows.

To make this first class (`tri viz graph`) the materialiser has to be ported to
`.t27` and generated by `t27c`, or the foreign-line budget has to be paid down
elsewhere; that is issue #12218's follow-up, not part of this document.
